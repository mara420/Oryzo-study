# ORYZO Study

Neoficiální studijní projekt, bez spojení s Lusion. Cíl: reprodukovat principy filmového 3D webu s maximální vizuální věrností a s bezplatnými licencovanými podklady. Originál: https://oryzo.ai/.

První milník: jeden živý WebGL záběr s oficiálním MIT modelem; žádné tvrzení o shodě bez vizuálního testu. Cizí webové soubory a nelicencované textury se nepublikují.
